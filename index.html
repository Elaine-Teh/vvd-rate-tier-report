Format
Client-Friendly HTML

Browser-based presentation format suitable for external sharing, review meetings, and management updates.

What this project presents
  • 1. Rate tier structure across main ports with FAK, T2, T1, and Spot split.
  • 2. Booking and TEU visibility to identify quality mix, revenue leakage, and upgrade opportunities.
  • 3. Management-focused commentary for commercial follow-up and action prioritization.
  • 4. Vessel cost extension using BY VV / 1st Estimation cost view for voyage-level reference.

What someone can explore inside the report

Overview: combined B/L, booking, TEU, and tier distribution snapshot.

Port tabs: per-port tier mix, booking detail, and container size structure.

Thresholds: rate threshold reference for pricing tiers by POD.

Freight Rate: POD-based freight view for China and SEA ports.

Vessel Cost: voyage-level BY VV estimation cost view.
