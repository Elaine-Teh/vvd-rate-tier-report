## VVD 搜索报告 - 运费率和分类修复

### 1. Freight Rate 计算方法修正
- **原方法**（错误）：`bl_freight_rate = total_freight / total_teu`（TEU 基础）
- **新方法**：`bl_freight_rate = total_freight / n_containers`（每箱基础）
- **效果**：TEU 方法导致运费率被稀释，使分类严重失准

### 2. Tier 分类逻辑修复
- **问题**：`get_tier_bl()` 始终使用 40' 阈值，导致 20' 箱型 B/L 被错误分类
- **修复**：按 B/L 实际箱型使用对应阈值
  - 纯 20' B/L：使用 20' 阈值（T1=2600, FAK=3000 for SAJED/EGSOK）
  - 纯 40' B/L：使用 40' 阈值（T1=3600, FAK=4000 for SAJED/EGSOK）
  - 混合 B/L：使用混合运费率 + 40' 阈值（40' TEU 占比更大）

### 3. Tier Distribution 结果对比
| Tier | 修正前 | 修正后 |
|------|--------|--------|
| FAK | 194 (19.6%) | 240 (24.3%) |
| T2 | 210 (21.3%) | 237 (24.0%) |
| T1 | 290 (29.4%) | 338 (34.2%) |
| Spot | 294 (29.8%) | 173 (17.5%) |

### 4. 重要教训
- `est_40()` 函数中的 `teu_40 = n_40 * 2` 导致 `rate_40 = total_freight / (n_40*2)` 错误地除以 2
- 纯箱型 B/L 的运费率 = `total_freight / n_containers`（每箱运费）
- 混合 B/L 的运费率无法从总运费唯一分解，需使用混合比率 + 对应阈值
