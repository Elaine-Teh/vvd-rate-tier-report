## Mixed B/L per-size rate 修复 (16:38)

**根因**: 对于 mixed-size B/L（同时有 20' 和 40' 箱），旧代码计算一个混合平均费率 `total_freight / n_containers`，两个 size 共用同一个费率 → 分类错误。

**用户要求**: 20' 用 20' 的费率对 20' 阈值分类，40' 用 40' 的费率对 40' 阈值分类。

**正确算法**: 按箱型分别汇总每箱费用
- `rate_20 = sum(20' charges: OFT+LSS+WRS+BAF) / n_20`
- `rate_40 = sum(40' charges: OFT+LSS+WRS+BAF) / n_40`

**验证 CULVNGB2613699** (1×20GP + 4×40HC):
- 20' charges: OFT $2,850 + LSS $50 = $2,900 / 1 cont = $2,900 → T1 (CNNGB SAJED T1=2900) ✅
- 40' charges: OFT $15,600 + LSS $400 = $16,000 / 4 cont = $4,000 → T1 (CNNGB SAJED T1=4000) ✅

**代码改动** (3 处 in `vvd_tier_analyzer.py`):
1. 新增 `freight_by_size` → `fr20_bl`/`fr40_bl` (per-B/L per-size 费用小计)
2. `bl_data['rate_20']` / `bl_data['rate_40']` 改为按 `freight_20/n_20` / `freight_40/n_40` 计算
3. `tier_stats` 改用 `merged` (per-container) 统计（支持 mixed B/L 分到不同 tier）
4. `pod_freight` 改用 `freight_20`/`freight_40`（避免 mixed B/L freight 重复计入）

**结果 ZGYC2617W CNNGB**:
- Spot: 324 (匹配用户 ✅) | T1: 1227 (用户 1229, 差 2 TEU) | T2: 16 | FAK: 0
